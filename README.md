# PALM official website — V8

2026-10-22 源码快照，包含已确认的最新版页面、8 张旅行/美食照片、轻柔入场及横向滑动、自然播放视频、手机布局和留资后端源码。

## 目录

- web/：可部署的静态网站入口 index.html、独立样式和脚本，以及全部引用的图片、视频。
- lead-api/：咨询信息 API、数据库迁移和测试。后端尚未部署。
- SOURCE-MANIFEST.json：原始源文件 SHA-256 清单，可核对入库快照。
- scripts/：本地预览与文件完整性检查。

## 本地预览与检查

需要 Node.js 24 或更高版本，无需安装依赖。在仓库根目录运行：

    npm run check
    npm test
    npm run preview

打开 http://127.0.0.1:4173 。视频和全部图片采用仓库中的相对路径。

## 发布准备

1. 网站发布目录选择 web/，不需要构建命令；同时上传其 assets/ 目录。不要把整仓库作为网站根目录。
2. 当前 web/lead-config.js 中 PALM_LEAD_ENDPOINT 为空，表单只做预览，不发送或保存真实咨询。
3. 正式收件前部署 lead-api/worker/index.js，创建 D1 数据库并绑定为 DB，按顺序应用 lead-api/drizzle/ 的两份 SQL。
4. 设置后端 ALLOWED_ORIGIN 为最终官网的完整来源地址，并把已验证的 /api/leads 地址写入 web/lead-config.js。若 API 与网站不同域，还要在 web/index.html 的 CSP connect-src 中允许该来源。
5. 用虚构资料完成一次实际提交，并确认数据库内出现同一条联系资料与服务需求记录后，再开放真实咨询。

后端目前仅提供写入接口；没有独立的后台管理登录页面，也没有自动邮件通知。不能把静态网页发布成功视为收件功能已经开通。数据库查询/管理和邮件通知需在正式发布配置中另行接通。

本次是源码保存和发布准备，不会自动部署网站。后端构建脚本采用独立可移植版本，不包含旧 Sites 项目编号。更新源码后应重新生成快照校验清单。

## 素材

仓库包含用户提供的官网使用素材及项目已有插画，保留它们随网站发布所需的文件。原始桌面视频、PDF、聊天附件、浏览器资料、真实客户信息和登录凭证未包含在此源码快照中。
