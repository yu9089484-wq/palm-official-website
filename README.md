# PALM official website — V8

2026-10-23 源码快照，包含 12 张旅行、美食与参访照片、两段自然播放视频、图片自动轮播、轻柔玻璃卡片及手机布局。手机端完整展示三项旅程内容与七项服务，并采用柔和彩色导航图标；原有正文和留资功能保持不变。

## 目录

- web/：可部署的静态网站入口 index.html、独立样式和脚本，以及全部引用的图片、视频。
- lead-api/：已部署的咨询信息 API、数据库迁移和测试。
- SOURCE-MANIFEST.json：原始源文件 SHA-256 清单，可核对入库快照。
- scripts/：本地预览与文件完整性检查。

## 本地预览与检查

需要 Node.js 24 或更高版本，无需安装依赖。在仓库根目录运行：

    npm run check
    npm test
    npm run preview

打开 http://127.0.0.1:4173 。视频和全部图片采用仓库中的相对路径。

## 发布配置

1. 网站发布目录选择 web/，不需要构建命令；同时上传其 assets/ 目录。不要把整仓库作为网站根目录。
2. web/lead-config.js 已接入正式 API。只有正式官网来源可提交；本地设计预览时请将端点设为空。
3. D1 数据库已绑定为 DB，两份 SQL 已应用；虚构测试资料已成功保存并回读核对。
4. 更换域名时同时更新 ALLOWED_ORIGIN、前端接口地址和 CSP connect-src。
5. 具体网站地址、项目标识和收件能力见 [DEPLOYMENT.md](DEPLOYMENT.md)。

后端提供写入接口，所有者可通过 Codex 的 Sites 数据库工具查看记录；没有独立的后台管理登录页面，也没有自动邮件通知。联系邮箱为 palm529018@gmail.com。

GitHub 保存源码，Sites 托管网站；推送 GitHub 不会自动部署。更新源码后应重新生成快照校验清单。
